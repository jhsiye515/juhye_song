# 예시 운영 데이터

가상 회사 「가나다커머스」의 클라우드 운영 데이터다. 실제 데이터와 무관하며, `python3 gen.py` 를 다시 돌리면 같은 값이 나온다(seed 고정).

- 기간: 2026-10-17 ~ 2026-11-16 09:00 (30일)
- IP: 문서용 대역(192.0.2.x · 198.51.100.x · 203.0.113.x)
- 메일: example.com

## 파일

| 파일 | 내용 | 건수 |
|---|---|---|
| all.json | 아래 전부 + 회사 · 부서 · 프로젝트 | |
| users.csv | 사용자 · 부서 · 역할(관리자 · 운영자 · 조회자) | 12 |
| servers.csv | 서버 · 클라우드(AWS · Azure · 사내 서버) · 사양 · 상태 | 58 |
| metrics_daily.csv | 서버별 일 평균 · 최대 CPU, 메모리, 디스크 사용률 | 1,713 |
| alerts.csv | 알림 · 규칙 · 등급(심각 · 경고 · 정보) · 확인 여부 | 320 |
| incidents.csv | 인시던트 · 우선순위(P1~P4) · 상태 · 담당 · 목표 시간 · 원인 · 묶인 알림 | 42 |
| costs_monthly.csv | 2026-06 ~ 11 프로젝트 · 클라우드별 컴퓨트 · 스토리지 · 네트워크 비용(원) | 114 |

인시던트 처리 이력(생성 · 처리 시작 · 해결 · 종료)은 all.json 의 `timeline` 에만 있다.

## 서로 맞는 값

- 인시던트의 서버 · 알림 · 담당은 모두 다른 파일에 있는 ID다.
- 알림은 사용률이 높은 서버 20대에 70%가 몰린다.
- 인시던트 해결 목표: P1 4시간 · P2 8시간 · P3 24시간 · P4 72시간.
- 최근 건은 처리 큐 시연용으로 신규 2 · 처리 중 4 · 해결 3이다.
