# 상태 배지

## 규칙

| 규칙 | 내용 |
| --- | --- |
| STATUS-01 | 상태는 점이 붙은 둥근 배지로 쓰고 글자로 상태 이름을 함께 쓴다. 색만으로 구분하지 않는다 |
| STATUS-02 | 색의 뜻: 초록 정상 · 끝남, 주황 진행 · 주의, 빨강 오류 · 초과, 파랑 새로 생김, 회색 멈춤 · 닫힘 |
| STATUS-03 | 서버 상태는 실행 중 초록 · 중지 회색 · 오류 빨강이다 |
