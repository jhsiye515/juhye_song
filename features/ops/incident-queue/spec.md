## 1. 개요

운영 › 인시던트에서 알림이 묶여 생긴 인시던트를 담당자에게 배정하고, 우선순위별 해결 목표 시간 안에 신규 → 처리 중 → 해결 → 종료 네 단계로 처리하는 기능을 정의한다.

| 항목 | 내용 |
| --- | --- |
| 메뉴 | 운영 › 인시던트 (처리 큐 · 처리 현황) |
| 범위 | 인시던트 등록 · 배정 · 상태 변경 · 목록 · 통계. 알림 규칙 설정은 알림 기획 |
| 근거 | 운영팀 요구사항(INC-RQ-01 ~ 04) |

## 2. 범례

| 구분 | 값 |
| --- | --- |
| 우선순위 | M 필수 · S 권장 · C 여유 시 |
| 권한 | A 관리자 · O 운영자 · V 조회자 |
| 난이도 | 1 단순 표시 · 2 상태 관리 · 3 서버 연동 · 배치 |
| 구분 | 신규 · 변경 · 유지 |
