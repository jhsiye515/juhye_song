## 2. INC-PL-STS-01 · 처리 상태와 행동

| 상태 | 뜻 | 바꾸는 행동 | 누가 |
| --- | --- | --- | --- |
| 신규 | 생겼고 담당이 없다 | 담당 맡기 → 처리 중 | 관리자 · 운영자 |
| 처리 중 | 담당이 처리하고 있다 | 해결 → 해결 | 담당 · 관리자 |
| 해결 | 원인을 고르고 해결했다 | 종료 → 종료 | 관리자 |
| 종료 | 확인을 마쳤다 | 없음 | — |

- 상태는 앞으로만 간다. 되돌리기는 INC-OQ-01.
- 상태를 바꾼 시각과 사람은 처리 이력에 남긴다.

## 3. INC-PL-GRP-01 · 알림 묶기

- 같은 서버에서 3시간 안에 생긴 심각 · 경고 알림을 인시던트 하나로 묶는다.
- 한 인시던트에 묶는 알림은 5건까지다. 6번째부터 새 인시던트를 만든다.
- 정보 등급 알림은 묶지 않는다.

## 4. INC-PL-SLA-01 · 해결 목표 시간

| 우선순위 | 목표 시간 | 기준 |
| --- | --- | --- |
| P1 | 4시간 | 서비스 전체가 멈춤 |
| P2 | 8시간 | 주요 기능 일부가 멈춤 |
| P3 | 24시간 | 성능 저하 · 우회 가능 |
| P4 | 72시간 | 영향 적음 |

- 경과 시간은 생성부터 지금까지, 해결 건은 해결 시각까지다.
- 막대 색: 목표의 75% 미만 초록 · 75% 이상 주황 · 100% 초과 빨강.
- 「목표 임박 · 초과」 숫자는 처리 대기 가운데 75% 이상인 건이다.

## 5. INC-PL-STT-01 · 목록 · 통계

- 빠른 보기 처리 대기 = 신규 + 처리 중, 해결 = 해결, 전체 = 모든 상태.
- 목록은 최근 생성 순이다.
- 목표 내 해결 비율 = 기간 안에 해결된 건 가운데 목표 시간 안에 해결된 건 ÷ 해결된 건.
- 원인 통계는 해결 · 종료 건의 원인을 센다.
